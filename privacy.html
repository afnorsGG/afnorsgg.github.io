Kebijakan Privasi DelPA

Terakhir diperbarui: 8 Oktober 2026

Ringkasan

DelPA adalah asisten pribadi privat untuk satu pengguna. DelPA hanya mengakses data Google milik pengguna yang secara eksplisit memberi izin melalui layar persetujuan Google.

Data yang diakses

  • Google Calendar: membaca, membuat, mengubah, dan menghapus acara.
  • Google Tasks: membaca, membuat, mengubah, dan menghapus tugas.
  • Google Drive: mencari dan membaca file, membuat dokumen dan folder, mengganti nama, memindahkan, dan memindahkan file ke Trash.
  • Google Sheets: membaca dan menulis spreadsheet.

Setiap aksi yang mengubah data hanya dijalankan setelah pengguna menyetujuinya secara eksplisit.

Penggunaan data

Data hanya dipakai untuk menjalankan permintaan pengguna. Data tidak dijual, tidak dipakai untuk iklan, dan tidak dibagikan kepada pihak ketiga, kecuali penyedia model AI yang memproses isi percakapan untuk menghasilkan jawaban.

Penggunaan dan transfer informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Penyimpanan

Token akses Google disimpan di server privat milik pengelola, di file yang hanya bisa dibaca oleh akun sistem DelPA. Data Google tidak disalin ke database terpisah.

Mencabut akses

Pengguna dapat mencabut akses kapan saja di myaccount.google.com/permissions. Setelah dicabut, DelPA tidak dapat lagi mengakses data Google pengguna.
